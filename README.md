# Marca de congelados desde cero

Curso práctico y autoguiado de 14 módulos para crear una marca de alimentos congelados: estrategia, nombre, logotipo, color, tipografía, empaque, familia de productos, manual de marca y etiquetado (Colombia).

Ábrelo en el navegador: todo el curso está en `index.html`.

## Cómo publicarlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `curso-marca-congelados`).
2. Sube los archivos de esta carpeta (`index.html` y este `README.md`) a la raíz del repositorio.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
5. En uno o dos minutos GitHub te mostrará la dirección pública, del tipo `https://TU-USUARIO.github.io/curso-marca-congelados/`.

## Fichas descargables

Cada plantilla se puede descargar como archivo HTML (se abre en cualquier navegador y se puede guardar en PDF con Imprimir). El curso indica a cada persona que envíe sus fichas descargadas a quien la acompaña. Las respuestas se guardan en el navegador de cada persona y pueden restaurarse subiendo una ficha descargada.
